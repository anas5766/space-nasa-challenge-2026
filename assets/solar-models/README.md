# Solar model assets

All GLB files in this directory are used by the local Three.js solar scene. Source pages, attributions, license notes, scale limitations, and offline-cache behavior are documented in [`docs/solar-assets.md`](../../docs/solar-assets.md).

`hyg-stars.csv` is a 12,000-record selection derived from the HYG Database v4.1. It retains catalog Cartesian coordinates, visual magnitude, and B–V color index. It is distributed under CC BY-SA 4.0; see the attribution and source link in the asset notes.
