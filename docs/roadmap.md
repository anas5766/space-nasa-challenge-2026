# Valmed Roadmap

## Current prototype

- Explain NASA's five human-spaceflight hazards and connect each one to the health indicators and mission context it may affect.
- Surface NASA Human Research Program and Canadian Space Agency resources beside the hazard they help explain.
- Let crew members record health readings and symptoms, review a local history, and view related anatomy in 3D.
- Offer optional local Ollama chat as non-clinical support for organizing information for the crew medical team.
- Present the experience as separate, responsive pages with collapsible navigation and a shared mission-themed visual system.
- Include optional focus, sequence-recall, and paced-breathing activities with locally saved scores.
- Verify the local Ollama model listing and chat route through the Node server before a presentation.

## Next development steps

1. Review all indicator ranges and action logic with space-medicine professionals and approved mission sources before any operational use.
2. Replace prototype values with crew-specific, clinician-approved limits and countermeasure plans.
3. Add data import from validated onboard sensors and document provenance for each reading.
4. Make mission-approved medical checklists available offline, with version and source attribution.
5. Evaluate the interface with astronaut and medical-officer scenarios, including loss of communication and urgent symptoms.
6. Add source-grounded answer retrieval for the local assistant and verify its safety behavior with reviewed scenarios.
